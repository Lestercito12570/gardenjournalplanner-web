# Garden Journal: Planner marketing website

Static public marketing site, separate from the Base44 SaaS application.

## Hosting

To mirror the MM-Promoter static site, enable GitHub Pages in Settings > Pages, deploy from the main branch, / (root). Set the custom domain to gardenjournalplanner.com and follow GitHub's displayed DNS requirements in Cloudflare. Enable HTTPS when available. Domain ownership verification is recommended before adding DNS. CNAME is included but does not itself enable Pages or configure DNS.

The SaaS remains at https://gardening.gardenshedclay.com. Keep that hostname working for existing links and installed applications.

## Content

Includes responsive layout, inline garden illustration, accessible navigation, FAQs, canonical URL, social metadata, sitemap and robots.txt. Illustrative journal text is labeled. No analytics or tracking scripts are installed. Pricing is intentionally delegated to the live app. App Store acquisition buttons should be added after the installed-app launch repair is verified.

## Validation

HTML parsed and local target links and structured data checked. Visual browser QA and live custom-domain/HTTPS verification remain outstanding. Source is buildless; no package installation or build command is required.
